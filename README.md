# PINKA Ai

PINKA Ai is a clean Flutter-based Android workspace for selecting video/subtitle files and preparing dubbing/translation workflows.

## Android APK

GitHub Actions builds a release APK automatically from the `main` branch. Open **Actions → Build PINKA Ai APK** and download the `PINKA-Ai-APK` artifact after the workflow completes.

Branding: PINKA Ai — pink/black theme.
